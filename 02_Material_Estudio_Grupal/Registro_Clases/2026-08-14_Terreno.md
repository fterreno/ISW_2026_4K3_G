Problemas con el desarrollo de software

* No se interpreta correctamente lo que el cliente quiere.
* Problemas de mantenimiento por código no limpio.
* Mala documentación.

**Software** = código + documentación + acuerdos (arquitectura, DBA, etc.). Software ≠ Manufactura. La manufactura consiste en producir elementos de forma repetitiva, como en una línea de montaje. El software no se puede producir de esa manera. Incluso si se desarrolla software con los mismos requerimientos, cada producto será intrínsecamente diferente.

**No Silver Bullet**. Existen dos características del software:

* Accidentales: relacionadas con la representación.
* Esenciales: relacionadas con el concepto.

Procesos definidos vs. procesos empíricos

| Proceso definido                                   | Procesos empíricos                   |
| -------------------------------------------------- | ------------------------------------ |
| Son predecibles.                                   | Aprendemos a medida que trabajamos.  |
| Para una misma entrada se obtiene la misma salida. | Trabajamos con variables cambiantes. |
|                                                    | Inspección → Adaptación          |

Ciclo de vida. Con la ejecución del proceso viene el **ciclo de vida**, que es una representación de un proceso.

**Proyecto vs. producto**

* El proyecto sobrevive al producto.
* El proyecto es la historia del proceso y tiene como salida el producto software.
* El proyecto representa la ejecución del proceso y la definición de actividades.

Tipos básicos de ciclo de vida. Existen tres tipos básicos:

1. Secuencial
2. Iterativo
3. Incremental
